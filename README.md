# OOP-Project
Academic Office Replacement

## Features for students

1. view timetable
2. view courses
3. view marks for each course
4. leave teacher feedback
5. view transcript
6. register for courses
7. see exams schedule + room allocations
8. a dashboard (main menu)

## Features for teachers

1. a dashboard (main menu)
2. mark each student
3. view each of their classes/ sections
4. view feedback results
5. venus and schedules

## Data Required (for students)
1. ID
2. Name
3. Type
4. GPA
5. email
6. Semester no./ batch
7. number of courses
8. Course infromation
9. exam and class schedules
10. grades and marks for each course's assessments
    
## Data Required (for Teachers)
1. ID
2. Name
3. email
4. Average Feedback
5. Assigned Courses
6. Assigned Sections
7. Marks of students
8. Designation
   
## Data Required (for Courses)
1. ID
2. Name
3. Quizzes + Exams + Assignments + their weightages + min/max/average
4. Teacher ID/ Name
5. Course Type
6. exam duration
7. marks
   
## Data Required (for Management)
1. Exam schedule
2. Venu Info= RoomID+ Capacity+ Has Computers
3. Sections Info: SectionID | CourseID | TeacherID | VenueID | TimeSlot
